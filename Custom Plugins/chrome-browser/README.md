# Chrome browser

English | [中文](README.zh.md)

This optional bundle installs the shared [browser-control provider](../browser-control/README.md), controller, and panel with visible Chrome as the default and Google as the homepage. Its IDs replace the legacy browser-control entries; do not layer both bundles in one profile. Run `install:custom-plugins` before adding it to a profile.

Configuration, session-owned tabs, explicit Playwright selection, cleanup, and tests are documented by the shared provider.
