# Agent Note: 桌面控制的 Tailscale 移动访问

Status: implemented

[English](2026-09-07-tailscale-mobile-access.md) | 中文

## Problem

仅监听回环地址的 Web 应用不能接受手机连接。将整个应用绑定到所有接口会使暴露范围超出预期 tailnet；独立移动安装会分离用户会话和设置。配对也需要保留现有应用的浏览器身份验证。

## Decision

[主机插件](../../../../packages/host/mobile-access/README.zh.md)在发现且已分配到本机的 Tailscale IPv4 地址上，以桌面端口提供第二个监听器。它共享现有 Web 分发器和浏览器身份验证所有者。监听器在所有路由前执行精确的 Host 和 Origin 策略，其主机授权仅适用于从该接口收到的请求。根路径启动令牌交换建立绑定主机地址的浏览器 cookie；资源、API 和升级请求均要求身份验证。

[客户端插件](../../../../packages/client/ui-mobile-access/README.zh.md)在回环桌面来源的设置旁提供手机图标。开关反映主机确认的状态。二维码在浏览器中编码现有身份验证启动 URL，不通过外部服务发布。手机打开同一个应用及其持久数据。

每个进程启动时访问均关闭。激活与停用按顺序执行。关闭或卸载插件会撤销接口信任，并等待附加监听器的 HTTP 和升级套接字关闭。桌面请求保留独立监听器。

移动布局将全部宽度交给会话内容，并通过左上角菜单以覆盖层打开侧边栏导航。选择会话通过布局的幂等关闭操作关闭覆盖层。触摸不激活悬停预览，也不通过悬停替换行内容，因此第一次点击即可触发 Session 操作。桌面鼠标悬停仍然可用，浏览器缩放保持启用。

URL 规范化使公布的主机地址与浏览器的 Host 和 Origin 标头保持一致，包括隐含的 HTTP 端口 80。

## Alternatives considered

**绑定所有接口。** 通配符监听器也接受局域网流量，无法让移动开关仅撤销 Tailscale 访问而不影响桌面。

**运行独立移动应用或反向代理。** 第二个应用产生另一套会话和配置生命周期。代理增加第二条 HTTP 和升级路径，其主机地址改写必须与身份验证保持一致。共享现有分发器可保留相同的路由所有者和身份验证应用。

**持久保存启用状态。** 每次重启后自动重新暴露应用，会使启动桌面应用同时成为网络访问决策。进程内默认关闭要求用户在桌面明确操作。

**在手机保留桌面轨道和悬停交互。** 常驻轨道占用有限的会话宽度。悬停触发的内容变化可能使触摸浏览器先显示悬停状态再分发点击，从而需要再次点击。移动覆盖层和稳定的触摸行在保留桌面功能的同时提供单次点击导航。

## Consequences

手机需要 Tailscale 连通性及允许应用端口的 tailnet 策略。配对授予现有应用的访问权限，而非受限移动角色。HTTP 使用 Tailscale 加密传输，但不满足所有浏览器安全上下文要求。此功能不配置 Tailscale、证书、公网访问或网络策略。

真实 Loader 组合测试覆盖关闭状态、身份验证、主机地址和 Origin 拒绝、受保护的 API 和资源、升级套接字关闭、激活失败、重复切换、排队清理及桌面连续可用性。地址发现测试覆盖命名接口、官方 CLI 结果、本地地址分配和平台可执行文件默认值。导航、响应式布局和二维码配对仍需浏览器验证；仅 HTTP 成功不能证明客户端可用。
