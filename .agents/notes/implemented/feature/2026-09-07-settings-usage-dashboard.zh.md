# Agent Note: 设置用量面板

Status: implemented

[English](2026-09-07-settings-usage-dashboard.md) | 中文

## Problem

用户需要查看历史 token 活动和模型用量，而不必额外收集一份对话副本或查阅供应商账单页面。

## Decision

[用量控制器](../../../../packages/api/usage-controller/README.zh.md) 通过现有持久化服务，从保留的会话事件派生统计。[用量设置插件](../../../../packages/client/ui-settings-usage/README.zh.md) 在标准组合中贡献第五个标签页，并呈现汇总指标、热力图、每日趋势和模型占比。

UTC 日期使不同浏览器的聚合保持一致。分支继承的事件不计入，因为源会话已拥有其用量。尝试结算保留重试报告的用量，且不会重复统计一次尝试及其最终消息。缺失用量单独报告，不进行估算。

最长会话时间衡量单个会话内已完成轮次的时长之和。会话包含空闲时间的存续时长不代表活动工作时间。

## Alternatives considered

**独立用量存储。** 从保留事件派生值可避免同步和重复的持久化统计，代价是在面板请求时读取历史。

**供应商账单总量。** 本地记录无需访问供应商特定账户即可支持多个供应商，但无法确定账单、价格或套餐配额。

## Consequences

删除的历史会从面板中消失，没有用量的尝试无法贡献 token 总量。面板保持只读，不改变模型可见输入。图表范围影响趋势和占比；全时段汇总指标保留其历史范围。
